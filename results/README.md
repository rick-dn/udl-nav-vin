| Folder | What |
|---|---|
| [baseline/](baseline/) | OpenVINS on the clean sim, scripted square flight |
| [faults/](faults/) | The same kind of flight replayed with injected faults: IMU noise and bias, time offset, dropped / frozen / dark / blurred frames |
